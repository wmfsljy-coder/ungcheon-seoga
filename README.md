# 웅천 서가

웅천고등학교 도서관 독서 프로그램 웹앱. 구글 시트를 데이터베이스로 쓰는 Google Apps Script 앱입니다.
학생은 책을 읽고 **라벨(한 줄 소개)·문장(책 속 한 문장)·독후감·북퀴즈**를 남기고, 도장 5개마다 별 1개, 별 2개마다 문화상품권을 받습니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `core.gs` | 모든 규칙과 계산. 시트·환경에 기대지 않는 순수 로직(`Core.make(db, env)`) |
| `Code.gs` | 구글 시트·메일·드라이브·트리거를 붙이는 껍데기(`doGet`, `doPost`, `api`, 시계, 백업) |
| `index.html` | 화면 전체(학생·교사·관리자·도서부) |
| `appsscript.json` | 매니페스트(권한, 웹앱 설정) |
| `설치안내.md` | 설치·운영 설명서와 운영 규정 문안 |
| `문서/` | 운영 계획서·교사 안내문·학생 안내문(워드) |
| `tools/` | 배포·시연본 빌드·자동 시험 |

## 시작하기

```bash
npm install -g @google/clasp     # 처음 한 번
clasp login                      # 스크립트를 가진 구글 계정으로
python tools/build_demo.py       # demo.html 만들기(브라우저로 바로 열림, 서버 없이 동작)
```

`demo.html` 은 구글 시트 대신 브라우저 localStorage 를 쓰는 시연본입니다. 계정을 골라 학생·교사·관리자·도서부 화면을 그대로 볼 수 있습니다.

## 시험과 배포

```bash
node tools/tests/stars.js        # 시험 하나만 돌리기
for f in tools/tests/*.js; do node $f; done
python tools/deploy.py "무엇을 고쳤는지"
```

`tools/deploy.py` 는 문법 검사 → 자동 시험 → 시연본 빌드 → `clasp push` → 같은 URL 로 재배포까지 한 번에 합니다.

배포 뒤 확인:

- `<앱주소>?status=1` — 판 번호, 이번 달 서가, 퀴즈, 장서 수 (공개)
- `<앱주소>?selftest=<열쇠>` — 26가지 자체 점검과 개통 준비 항목 (열쇠는 저장소에 없습니다. 코드에는 SHA-256 해시만 있습니다)

## 데이터와 개인정보

- 학생 정보(학번·이름·글)는 **구글 시트에만** 있습니다. 이 저장소에는 들어 있지 않습니다.
- 로그인은 학번(교사는 이름) + PIN 여섯 자리입니다. PIN 은 시트에 해시로만 저장하고, 구글 메일은 쓰지 않습니다.
- 게시판에는 이름 없이 학급만 나옵니다. 이름은 담임·담당 교사만 봅니다.
- 보유 기간: 3학년은 졸업식 날까지, 1·2학년은 학년말까지.
- 자체 점검 열쇠(`tools/.testkey`)와 배포 기록은 `.gitignore` 로 빼 두었습니다.

## 규칙 한눈에

- 한 주 도장은 **자리 다섯 칸**: ① 라벨·문장(둘을 합쳐 한 칸) ② 독후감 ③ 퀴즈 출제 ④ 퀴즈 풀이 ⑤ 만능.
- 같은 자리를 그 주에 또 채우면 **책갈피 한 장**(자리마다 주 1장), 그 뒤에 낸 글은 기록만 남습니다.
- **책갈피 5장 = 만능 도장 1개**(한 주 1개). 남은 책갈피는 다음 주로 넘어갑니다.
- 이달의 추천 도서·이 주의 주제 독후감, 이벤트 배수, 미션 보상은 자리와 상관없는 **덤 도장**(주 5개까지)입니다.
- 별 1개 = 도장 5개(종류 조건 없음). 도장과 별은 달이 바뀌어도 쌓입니다.
- 투표: **라벨·문장·독후감 세 부문, 부문마다 한 주 2표.** 글은 올라온 날부터 **7일** 동안만 투표 대상이고, 달마다 부문별 **3위 안 = 만능 도장 1개**.
- 별 2개 = 문화상품권 5,000원 1매, 한 번에 2매까지. 받거나 기간이 지나면 별은 사라집니다.
- 추천 도서는 매달 1일, 청소년 권장도서 목록(`권장도서` 시트) 가운데 학교가 소장한 책에서 12개 영역 40권.
